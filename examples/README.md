# Catalog examples

This directory holds deliberate public showcase media referenced by the repository README. Existing paths under `skills/media/` are retained for compatibility with published links; here `skills` is the rendered wordmark text, not an installable skill directory.

Installable fixtures belong in `skills/<slug>/examples/` inside the relevant skill so the official skills CLI copies them with the workflow. In particular, the draw.io [synthetic example](../skills/drawio-system-design/examples/model.json) and [reviewed preview](../skills/drawio-system-design/examples/rendered/architecture.png) live with that skill.

Do not add temporary experiments or private project architecture here. Wordmark media can be recreated using the [wordmark workflow](../skills/animate-ascii-wordmark/SKILL.md); retain its generated licenses and notices when distributing generated bundles.
